Getting Started

Nova is a lightweight, zero-dependency MVC web framework for Python. It is designed to be fast, simple, and strictly structured, offering a modern developer experience without the bloat of heavy third-party libraries.

Prerequisites

  • Python 3.8+
  • Built-in sqlite3 (default driver)
  • Optional: pymysql (for MySQL) or psycopg2-binary (for PostgreSQL)

Installation

# 1. Clone your repository
git clone https://github.com/yourusername/nova.git
cd nova

# 2. Setup your environment variables
cp .env.example .env

# 3. Start the development server
python nova.py serve

Directory Structure

Nova enforces a strict, predictable MVC architecture to keep your code organized as it grows.

  • app/: Your application code.
    • Http/Controllers/: Houses your route controllers.
    • Models/: Your Nova-ORM database models.
  • engine/: The core framework code (Routing, DB, ORM, Request/Response). Do not modify.
  • database/: Stores SQLite databases (if using the default driver).
  • public/: The document root. Contains index.py (Front Controller) and static assets.
  • resources/views/: Your HTML templates.
  • routes/: Contains web.py where all HTTP routes are registered.

Configuration

Application configuration is handled via the .env file at the root of your project. The framework includes a custom dependency-free parser.

You can access these variables anywhere in your app using the env helper function:

from engine.Support.env import env

# Get a value, or provide a default if missing
api_key = env('API_KEY', 'default_fallback_value')
db_driver = env('DB_CONNECTION', 'sqlite')

Routing & Controllers

Routes are registered in routes/web.py. Nova maps HTTP methods and URIs directly to Controller methods.

Defining Routes

# routes/web.py
def register_routes(router):
    router.get('/', 'HomeController@index')
    router.post('/users', 'UserController@store')

Creating Controllers

You can generate a controller quickly using the Nova CLI:

python nova.py make:controller UserController

Controllers receive a Request object and must return a Response.

# app/Http/Controllers/UserController.py
from engine.Http.request import Request
from engine.Http.response import Response

class UserController:
    def store(self, request: Request) -> Response:
        name = request.post.get('name')
        return Response(f"User {name} created!", 201)

Database & Nova-ORM

Nova includes a powerful, zero-dependency Active Record implementation called Nova-ORM. It natively supports SQLite, MySQL, and PostgreSQL based on your .env configuration.

Defining a Model

Models live in app/Models/. By default, Nova assumes the table name is the plural, lowercase version of the class name.

from engine.Database.model import Model

class User(Model):
    # Optional: override default table name
    # __table__ = 'custom_users_table'
    pass

Basic CRUD Operations

# Create
user = User.create(name="Alice", email="alice@example.com")

# Read
users = User.all()            # Fetch all
user = User.find(1)           # Fetch by PK
admins = User.where('role', 'admin') # Filter

# Update
user = User.find(1)
user.name = "Alice Nova"
user.save()

# Delete
user = User.find(1)
user.delete()

Relationships

Nova-ORM supports has_many and belongs_to relationships for easy data retrieval.

# app/Models/User.py
class User(Model):
    def posts(self):
        return self.has_many(Post)

# app/Models/Post.py
import app.Models.User as UserModule

class Post(Model):
    def author(self):
        return self.belongs_to(UserModule.User)

CLI Commands

The nova.py file acts as your command-line assistant.

Command Description
python nova.py serve Boots the WSGI server on the host/port defined in .env.
python nova.py make:controller [Name] Scaffolds a new controller in app/Http/Controllers/.
